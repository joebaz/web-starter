# Astro Web Starter

A template for informational websites for small and medium-sized businesses, and the agent workflow that builds them.

## Language

### Code health

**Technical debt**:
A shortcut or omission in the code, such as duplication, a missing test, or a workaround, that makes later changes slower or riskier until it is paid down.
_Avoid_: tech debt, cruft

**Design debt**:
A mismatch between how the code is divided and named and what the site now needs, such as a misplaced boundary, a component doing two jobs, or a one-off style where a shared token belongs.
_Avoid_: architecture debt

## Flagged ambiguities

- "Design" also means the site's visual design. **Design debt** is about the code's structure, including how shared components and tokens carry the visual design, not a judgement of the visual design itself.
