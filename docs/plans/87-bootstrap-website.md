Preserve a stock name that overlaps a canonical label and set its canonical metadata. Never delete arbitrary custom labels to achieve an exact-set check: report them for a separate decision. Send `delete_branch_on_merge` as a JSON boolean (`gh api -F delete_branch_on_merge=true` or equivalent JSON), not a raw string. No file edits, Project/wiki/issue operations, branch protection, rulesets, other settings, or CI reruns in apply.

Exit `0` only when the allowed apply subset is read back successfully; exit `2` on refusal, invalid invocation, read/mutation failure or incomplete readback. On partial failure, report what changed and what failed; do not claim rollback or overall success. A retry repeats only the allowed reconciliation.
